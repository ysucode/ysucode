# هلا، أنا يوسف 👋

طالب هندسة ذكاء اصطناعي، على مشارف التخرج.

أبني نماذج وأجربها في Jupyter Notebook، وأتعلم من كل تجربة. وبعد الدوام أشرح الذكاء الاصطناعي بالعربي وأسوي ريلز بأدواته.

## اللي أشتغل عليه الحين

- نماذج ذكاء اصطناعي أجربها في Notebooks
- [arabic-reels-skills](https://github.com/ysucode/arabic-reels-skills): سكلين لـ Claude Code أسوي فيهم ريلز أنميشن بالعربي. «رواية» لفيلم بلقطة وحدة من قصة حقيقية، و«انمي» لريل بمقاطع Seedance
- صفحة روابطي، بنيت لها محرر ومعاينة بنفسي

## اللي أعرفه

أدرس الشبكات العصبية والذكاء الاصطناعي، وأساسيات الخوارزميات وهياكل البيانات وهندسة البرمجيات والشبكات. وتحت هذا كله رياضيات: جبر خطي وإحصاء وتفاضل وتكامل ورياضيات متقطعة.

## وأقدّم خدمات

مونتاج وموشن جرافيك وتعليق صوتي.
